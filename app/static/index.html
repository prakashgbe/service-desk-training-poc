YOUR MODULE

Learn the process

SOP-NET-001
01

LESSON 1

Gather information first

Before changing any settings, record the employee's reported problem, laptop asset identifier, location, whether one or multiple employees are affected, when the issue started, and any recent password or laptop configuration changes.

Key principle

Gather and record initial information before changing settings.

02

LESSON 2

Follow the troubleshooting steps

1
Check basic connectivity

Confirm Airplane Mode is off, Wi-Fi is enabled, and the corporate network name is visible. Record results.

2
Determine the scope

Ask whether others in the same location are affected. Record the location and number of users when multiple users are affected.

3
Check authentication

Ask about recent password changes and record authentication errors. Never ask for the employee's password or bypass security controls.

4
Check network configuration

Inspect IP configuration only if permitted by endpoint troubleshooting policy. Record the IP address and relevant errors.

5
Record findings

Document checks, results, error messages, actions taken, and whether connectivity was restored.

03

LESSON 3

Know when to escalate

Escalate when multiple employees appear affected, authentication requires privileged investigation, security or compliance controls may be involved, the issue persists after approved initial checks, or the next action requires permissions you do not have.

Do not assume an outage

Do not independently declare a network outage without sufficient evidence. Include troubleshooting evidence in the escalation.

04

LESSON 4

Verify before resolving

The incident can be considered resolved when the employee confirms the laptop connects to corporate Wi-Fi and the engineer records the verification result. If connectivity cannot be restored, document the evidence and follow the escalation procedure.

Remember

Taking an action is not proof of success. Verify the outcome and record it.

RECAP

Quick knowledge check

6 questions

Check your understanding. These questions are based on SOP-NET-001.

1. What should you record before changing settings?

The reported problem, laptop asset identifier, employee location, whether one or multiple employees are affected, when the issue started, and recent password or laptop configuration changes.

2. What if multiple employees are affected?

Record the affected location and number of users, then escalate suspected widespread connectivity issues according to the organization's network incident procedure. Do not declare an outage without sufficient evidence.

3. Can you ask an employee for their password?

No. Do not request or record user passwords.

4. When may you inspect IP configuration?

Only if permitted by the organization's endpoint troubleshooting policy.

5. What should an escalation include?

Troubleshooting evidence, including checks performed, results, error messages and actions taken.

6. What must happen before resolving the incident?

The employee confirms that the laptop connects to corporate Wi-Fi, and the engineer records the verification result.
